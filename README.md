# CPE 4669 - Distributed Systems

For running labs that involve Python, we use a uv virtual environment. From the
repository root, install uv and create the environment:

```sh
python -m pip install uv
uv sync
```

Then activate it on Windows PowerShell:

```powershell
.\.venv\Scripts\Activate.ps1
```

On macOS or Linux:

```sh
source .venv/bin/activate
```
